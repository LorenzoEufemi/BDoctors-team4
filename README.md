# BDoctors

Applicazione web ispirata a "Il Mio Dottore", pensata per connettere utenti e medici.

## Tecnologie
- HTML, CSS, JavaScript
- Vue.js
- PHP, Laravel
- MySQL

## Funzionalità
- Ricerca di medici per categoria e visualizzazione profili
- Recensioni sui medici
- Registrazione medici con inserimento dati e curriculum
- Area privata per i medici

## Descrizione
Progetto full-stack sviluppato durante il corso Boolean. Creato per migliorare la UX e l’organizzazione delle informazioni, con particolare attenzione alla chiarezza del flusso e all'usabilità.
